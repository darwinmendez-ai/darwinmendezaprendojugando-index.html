# Aprendo Jugando – Recurso Educativo Digital

Recurso educativo interactivo desarrollado para el componente de **Orientación Educativa y Familiar** (Vinculación con la Sociedad), dirigido a un estudiante con necesidades educativas asociadas a síndrome de Down.

## 🎯 Descripción

Aplicación web de una sola página (HTML/CSS/JavaScript, sin dependencias de instalación) con actividades interactivas de aprendizaje: reconocimiento de situaciones, rompecabezas, secuencias, asociación de memoria y un juego de días/meses, con apoyo de síntesis de voz (Web Speech API) para lectura en voz alta.
